# سامانه تحلیل رفتارشناسی و سلامت روابط عاطفی (Love Analyzer v5.0)

یک وب‌اپلیکیشن تمام‌عیار و راست‌به‌چپ (RTL) برای ارزیابی علمی روابط عاطفی، تحلیل الگوهای رفتاری، مدیریت تعارض و سنجش سازگاری زوجین. این پروژه با ترکیب چارچوب‌های معتبر روانشناسی روابط—از جمله **نظریه دلبستگی (ECR)**، **مدل ۴ سوار جان گاتمن**، **ارتباط بدون خشونت (NVC)** و **پنج زبان عشق گری چاپمن**—ساخته شده و تمامی داده‌های شخصی کاربر را به‌صورت محلی در مرورگر نگهداری می‌کند.

---

## چرا این پروژه را ساختم؟

اکثر ابزارهای تحلیل رابطه یا به چند تست سطحی و سرگرمی محدود می‌شوند یا ساختار علمی مشخصی ندارند. هدف من در طراحی این سامانه این بود که یک داشبورد یکپارچه و دقیق با رابط کاربری فارسی (فونت Vazirmatn) بسازم تا فرد بتواند به‌جای قضاوت‌های هیجانی، رفتارها، مرزهای شخصی، سبک دلبستگی و نقاط اصطکاک رابطه‌اش را در قالب داده‌های عددی، نمودار راداری و سناریوهای عملی بررسی کند.

---

## ماژول‌ها و امکانات اصلی

این سامانه از **۱۱ بخش تعاملی مستقل** تشکیل شده که در یک ساختار ماژولار به هم متصل‌اند:

1. **سنجش جامع خلوص و رفتارشناسی رابطه (`QuizModule` & `ResultDashboard`)**
   - دارای دو حالت **سنجش سریع (۸ سناریو)** و **سنجش کامل (۲۰ سناریو)**.
   - محاسبه امتیاز در ۶ محور کلیدی: *همدلی و درک عاطفی*، *تعهد عملی و ثبات*، *صداقت و شفافیت*، *بلوغ عاطفی و خودتنظیمی*، *حل تعارض و مهار خشم* و *حریم شخصی و استقلال*.
   - رسم نمودار راداری ۶بعدی با Canvas اختصاصی و تولید **شناسنامه تصویری (PNG)** قابل دانلود برای بایگانی شخصی.

2. **تعمیرگاه تعارض و فرمول‌ساز NVC (`ConflictRepairModule`)**
   - شناسایی ۴ الگوی مخرب جان گاتمن (انتقاد تند، تحقیر، حالت تدافعی و قهر خاموش) در مشاجرات.
   - بازنویسی جملات تنش‌زا به ساختار ۴ مرحله‌ای **ارتباط بدون خشونت (مشاهده، احساس، نیاز، درخواست)**.

3. **شبیه‌ساز سناریوهای بحرانی و سنجش EQ (`RoleplaySimulatorModule`)**
   - تمرین مکالمه در موقعیت‌های چالش‌برانگیز عاطفی با محاسبه شاخص هوش هیجانی و امنیت روانی در هر مرحله از گفتگو.

4. **قطب‌نمای دلبستگی بزرگسالان ECR (`AttachmentCompassModule`)**
   - ارزیابی دقیق جایگاه فرد روی دو محور **اضطراب عاطفی** و **اجتناب از صمیمیت** و ارائه راهکارهای حرکت به سمت دلبستگی امن.

5. **ماتریس هم‌راستایی ارزش‌ها و اهداف بلندمدت (`ValuesAlignmentModule`)**
   - مقایسه دیدگاه دو طرف در ۸ ستون اساسی زندگی مشترک (مالی، خانواده، استقلال، سبک زندگی و تعهد) و کشف نقاط اصطکاک پنهان پیش از تصمیم‌های جدی.

6. **سنجش تطابق ۵ زبان عشق (`LoveLanguageModule`)**
   - اولویت‌بندی زبان‌های عشق طرفین و بررسی هم‌پوشانی شیوه ابراز و دریافت محبت به همراه ذخیره وضعیت در مرورگر.

7. **رادار رفتارهای سمی (`ToxicRadarModule`)**
   - چک‌لیست تخصصی برای ردیابی الگوهای آسیب‌زایی مثل وارونه‌نمایی (Gaslighting)، بمباران عشقی (Love Bombing)، قهر تنبیهی و کنترل‌گری پنهان.

8. **کالبدشکافی متن و مکالمات (`ChatForensicsModule`)**
   - بررسی پیام‌ها و مکالمات ثبت‌شده جهت تشخیص زیرمتن (Subtext)، لحن پنهان و پیشنهاد پاسخ‌های بالغانه و مرزبند.

9. **گاهشمار و نمودار نوسانات رابطه (`RelationshipTimelineModule`)**
   - ثبت نقاط عطف (Milestones) و امتیازدهی دوره‌ای برای رصد افت‌و‌خیز کیفیت رابطه در طول زمان.

10. **دستیار گفتگو و راهنمای تعاملی روابط (`CoachChatModule`)**
    - محیط گفتگوی متنی که با در نظر گرفتن نتایج آخرین آزمون ذخیره‌شده کاربر، پیشنهادهای عملی متناسب با شرایط همان رابطه ارائه می‌دهد.

11. **دانشنامه تخصصی روانشناسی روابط (`WisdomLibraryModule`)**
    - مجموعه مقالات خلاصه و کاربردی درباره متد گاتمن، سبک‌های دلبستگی، مدیریت طغیان هیجانی و مرزبندی سالم.

- **امکانات جانبی رابط کاربری:** آرشیو تاریخچه آزمون‌ها (`HistoryModal`)، راهنمای متدولوژی (`InfoModal`)، بازخورد صوتی سبک با Web Audio API (قابل قطع و وصل از هدر) و پس‌زمینه پویا با ذرات شناور.

## تکنولوژی‌ها و معماری پروژه

- **فرانت‌اند:** React 19، TypeScript، Tailwind CSS v4، Motion، Lucide React، Canvas API، Canvas Confetti
- **بک‌اند و سرور:** Node.js، Express، ادغام Vite Middleware در محیط توسعه و سرو فایل‌های استاتیک باندل‌شده در محیط پروداکشن (`esbuild`)
- **ذخیره‌سازی و حریم خصوصی:** استفاده کامل از `localStorage` مرورگر برای نگهداری تاریخچه آزمون‌ها، نقاط گاهشمار و پروفایل زبان عشق بدون ارسال یا ذخیره اطلاعات خصوصی در دیتابیس ابری.

### ساختار فایل‌ها

```text
.
├── server.ts                        # سرور Express و روت‌های API تحلیلی + اجرای Vite
├── index.html                       # تنظیمات RTL، متادیتا و فونت Vazirmatn
├── package.json                     # اسکریپت‌های بیلد، توسعه و وابستگی‌ها
├── vite.config.ts                   # پیکربندی Vite و Tailwind
└── src/
    ├── App.tsx                      # مدیریت تب‌ها، وضعیت سراسری و مودال‌ها
    ├── types.ts                     # تایپ‌های TypeScript برای آزمون، ابعاد و تحلیل‌ها
    ├── data/                        # بانک سناریوها، پرسش‌نامه‌ها، پریست‌ها و مقالات
    │   ├── quizQuestions.ts
    │   ├── attachmentECRData.ts
    │   ├── conflictPresets.ts
    │   ├── chatPresets.ts
    │   ├── loveLanguagesData.ts
    │   ├── roleplayScenarios.ts
    │   ├── toxicRadarData.ts
    │   ├── valuesData.ts
    │   └── wisdomArticles.ts
    ├── utils/
    │   ├── audio.ts                 # افکت‌های صوتی تعاملی با Web Audio API
    │   ├── canvasExport.ts          # تولید و خروجی گرفتن شناسنامه تصویری PNG
    │   └── storage.ts               # مدیریت localStorage برای تاریخچه و گاهشمار
    └── components/                  # کامپوننت‌های مستقل هر ۱۱ ماژول + هدر و نمودار راداری
```

## اندپوینت‌های سرور (`server.ts`)

| متد | مسیر | کاربرد |
| :--- | :--- | :--- |
| `GET` | `/api/health` | بررسی وضعیت سلامت و فعال بودن سرور |
| `POST` | `/api/analyze-quiz` | تولید گزارش تشریحی ۵بخشی از نتایج آزمون ۶بعدی |
| `POST` | `/api/analyze-chat` | کالبدشکافی پیام، تشخیص زیرمتن و پیشنهاد پاسخ |
| `POST` | `/api/coach-chat` | پردازش گفتگوی راهنمای روابط بر اساس سابقه کاربر |
| `POST` | `/api/compatibility-check` | تحلیل تطابقی ۵ زبان عشق زوجین |
| `POST` | `/api/conflict-deescalate` | شناسایی ۴ سوار گاتمن و بازنویسی به فرمول NVC |
| `POST` | `/api/roleplay-step` | پردازش گام‌به‌گام سناریو و امتیازدهی EQ |
| `POST` | `/api/values-alignment` | ارزیابی هم‌راستایی ۸ ستون ارزش‌های مشترک |
| `POST` | `/api/attachment-deep-analysis` | تحلیل عمیق مختصات دلبستگی ECR و برنامه ترمیم |

## راهنمای نصب و اجرا

برای اجرای پروژه روی سیستم شخصی خود، مراحل زیر را انجام دهید:

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/Reza-Mokhtari-Hub/<REPO_NAME>.git
cd <REPO_NAME>
```

### ۲. نصب پکیج‌ها
```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی
یک فایل `.env` در ریشه پروژه بسازید (می‌توانید از فایل `.env.example` کپی بگیرید) و کلید API مورد نیاز پردازشگر متن سمت سرور را در آن قرار دهید:
```bash
cp .env.example .env
```

### ۴. اجرای سرور توسعه
```bash
npm run dev
```
سپس مرورگر را باز کنید و وارد آدرس زیر شوید:
```text
http://localhost:3000
```

### ۵. بیلد و اجرای نسخه نهایی (Production)
```bash
npm run lint
npm run build
npm start
```
